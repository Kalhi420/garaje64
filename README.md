# Garaje 64

App web para coleccionistas de autos a escala 1:64: escanea el código del blíster, cataloga tu colección, lleva el valor, repetidos, intercambios y listas.

**Úsala aquí:** https://kalhi420.github.io/garaje64/

En iPhone: ábrela en Safari, toca Compartir → "Agregar a inicio" y ábrela siempre desde ese ícono. Tus autos se guardan en el teléfono y no se borran.

Garaje 64 es independiente y no está afiliada a ningún fabricante de juguetes. Datos del catálogo: listas públicas de coleccionistas (munclemikes.com, 164custom.com). Lectura de códigos con Tesseract.js (Apache 2.0).
